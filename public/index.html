Privasi Terjaga & Kendali Akun di Tangan Anda

Kami meyakini data produktivitas dan finansial Anda adalah catatan pribadi. Pulse dirancang dengan pengelolaan akun yang bersih dan tanpa pelacakan pihak ketiga.

  • ✓ Kata sandi di-hash aman menggunakan algoritma Bcrypt
  • ✓ Pertukaran data dilindungi protokol transmisi HTTPS/TLS
  • ✓ Hak hapus akun permanen (Right to be Forgotten) satu klik
🔒 Protokol Keamanan Berlapis
Bcrypt Password Hashing: Kata sandi tidak pernah disimpan dalam plain text.
JWT Session & Expiry: Sesi aman dengan token kedaluwarsa berkala.
Bebas Iklan & Pelacak: Kami tidak pernah menjual data Anda ke pengiklan pihak ketiga.

Pertanyaan yang Sering Diajukan

Punya pertanyaan seputar fitur dan keamanan aplikasi Pulse? Temukan jawabannya di bawah ini.

Apakah Pulse menghubungkan langsung ke rekening bank saya? +

Tidak. Pulse berfungsi semata-mata sebagai alat bantu pembukuan pribadi mandiri (personal expense tracker). Pulse tidak terhubung ke API rekening bank atau e-wallet, sehingga Anda memiliki kendali manual penuh atas data yang ingin dicatat tanpa risiko transaksi otomatis.

Bagaimana cara kerja penghapusan akun permanen? +

Anda dapat menghapus akun kapan saja melalui menu Profil > Hapus Akun di dalam aplikasi mobile. Sistem akan mengeksekusi penghapusan database menyeluruh (tugas, catatan, kebiasaan, riwayat transaksi, anggaran, dan data login) secara permanen dan tidak dapat dipulihkan kembali.

Apakah saya bisa menggunakan Pulse saat offline? +

Ya. Aplikasi menyimpan cache lokal di perangkat Anda menggunakan penyimpanan aman lokal sehingga Anda tetap dapat membuka riwayat tugas dan catatan saat jaringan internet tidak stabil.

Bagaimana cara kerja notifikasi peringatan anggaran (Budget Alert)? +

Ketika total transaksi pengeluaran bulanan Anda telah mencapai ambang batas yang Anda tentukan (misalnya 80% atau 100% dari limit anggaran kategori), Pulse akan memicu notifikasi peringatan cerdas agar Anda dapat mengontrol pengeluaran sebelum overbudget.
